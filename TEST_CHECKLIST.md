# Test checklist

## Build environment
- Date:
- OpenGOAL Launcher version:
- Jak 3 region/version, if known:
- Windows version:
- Mod base commit/tag:
- Build command:
- Result: PASS / FAIL / BLOCKED

## Asset checks
- [ ] GLB opens in an independent viewer.
- [ ] Scale and orientation are correct.
- [ ] No missing asset dependencies.
- [ ] Collision source is generated and documented.
- [ ] Package contains no ISO or extracted copyrighted game data.

## In-game checks
- [ ] Launcher recognizes the mod.
- [ ] Mod installs without errors.
- [ ] Jak 3 starts with the mod enabled.
- [ ] New content is reachable.
- [ ] Player spawn is safe.
- [ ] Ground and platform collision work.
- [ ] Restart/respawn works.
- [ ] No crash or unrecoverable softlock.

## Failure report
Paste the exact error text and describe the last action before the error. Add a screenshot if possible.
