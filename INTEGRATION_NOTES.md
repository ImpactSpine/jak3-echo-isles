# Integration notes — Echo Isles / Jak 3

The public custom-level guide documents the core pipeline (GLB geometry, JSONC actor/level metadata, DGO `.gd`, compiler and debug Continue-point), but its worked example is Jak 1. It explicitly says the custom-level tooling is early-stage. Treat the files in this kit as a starting point only.

## Do not overwrite your installed game
Work in a copy of the OpenGOAL mod base. Do not place these files directly into your ordinary Launcher install unless your chosen mod base documentation says to.

## Required integration work (must be checked against the current Jak 3 base)
- Place `echo-isles.glb` under the mod base's Jak 3 custom-level asset folder.
- Place the JSONC next to the other custom-level JSONC files and verify the `gltf_file` path convention.
- Add a matching custom-level definition to the Jak 3 `game.gp`.
- Add the correct level-info/continue-point registration with a unique index and coordinate system for Jak 3.
- Ensure the DGO's level `.go` is generated by the current compiler pipeline and the `.gd` references the exact generated object name.
- Run the mod-base build command; do not assume successful compilation from the presence of these files.
- Load the continue-point in debug mode, confirm the player spawns on the broad central island, and inspect collisions.

## Why no automatic installer is included
OpenGOAL mod-base folder layouts and integration files can vary by mod-base branch and tooling version. An automatic copy script without knowing your exact mod base could put files in the wrong location or silently overwrite project files. The safest next step is to inspect the local mod-base directory tree and adapt the integration to it.
